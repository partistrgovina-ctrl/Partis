Dobrodošli

Program radi preko interneta, sa bilo kog računara i pregledača. Ne treba vam nikakav folder. Upišite GitHub ključ (pravi se jednom, uputstvo je ispod) i kliknite „Uđi“. Artikle menjate, pa kliknete „Objavi na sajt“.

Kako da napravim GitHub ključ

Na github.com prijavite se vašim nalogom, pa: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Izaberite samo repozitorijum Partis, a pod Permissions → Contents postavite Read and write. Ključ nalepite gore. Čuva se samo u ovom pregledaču.

Stari način (folder na računaru, samo Chrome/Brave):

Izmene još nisu na sajtu. Kada završite, kliknite „Objavi na sajt“ — sajt se sam osveži za oko minut.
