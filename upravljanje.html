Dobrodošli

Program radi preko interneta, sa bilo kog računara i pregledača. Ne treba vam nikakav folder. Upišite GitHub ključ (pravi se jednom, uputstvo je ispod) i kliknite „Uđi“. Artikle menjate, pa kliknete „Objavi na sajt“.

Kako da napravim GitHub ključ

Prijavite se na github.com kao vlasnik repozitorijuma, pa otvorite github.com/settings/tokens/new (klasičan ključ). Pod „Select scopes“ štiklirajte samo repo, kliknite Generate token i nalepite ključ (ghp_…) gore. Čuva se samo u ovom pregledaču.
